# Zenodo detection images

Small reproducible subset used to develop and validate the brick detector.

## Source and license

- Dataset: *Bricks Detection Dataset*
- Authors: Dominik Štursa, Petr Doležel, Daniel Honc, Vítek Rais, and Tomáš Novák
- Publisher: University of Pardubice
- DOI: https://doi.org/10.5281/zenodo.18952529
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
