The team's full working repository, with the complete history, datasets, model weights and
recorded artifacts, is private. This repository is a curated public copy, published with the
agreement of every author, so the work can be read without cloning over a gigabyte.

Each folder is a filtered snapshot rather than a merge of the original branches, so the git
history here starts fresh. Authorship is recorded on the commit that introduces each folder and
in this file.
