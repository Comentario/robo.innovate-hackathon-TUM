# Working conventions

- Use English for all user-visible visualizations, demos, scenario names, labels,
  tooltips, charts and presentation artifacts. Documentation may be in Spanish.
- Communicate with the project owner in Spanish.
- Work on `persona2/planning`; keep perception, planning and execution modular.
- Create a commit for each coherent change after appropriate verification.
- Keep synthetic assumptions explicit. Do not present team heuristics as official requirements.
